Phasor view each constituent as a rotating vector f·H at angle V+u−κ; the tide height is the sum of x components. Animates at 600× real time.

Engine: tides.js, a JavaScript port of the constituent definitions in Schureman SP-98 as encoded by pytides and XTide's congen, validated against NOAA predictions in test_tides.js. Data: NOAA CO-OPS metadata API (harmonic constituents and datums).
